# Курс Python: уроки и домашки

Сайт курса «Программирование на Python»: все уроки, презентации и интерактивные домашние задания.
Код учеников запускается прямо в браузере настоящим Python (Pyodide), включая `input()` и черепашку `turtle` — ничего устанавливать не нужно.

**Адрес сайта:** https://svet04ka.github.io/python/

## Что на сайте

| Страница | Что это |
|---|---|
| `index.html` | Главная: все 11 уроков, темы, ссылки на домашки, презентации и материалы в Colab |
| `hw/urok-2.html` … `hw/urok-8.html` | Домашки: повторение теории, разбор задачи, квиз, «найди ошибку», задачи с автопроверкой и звёздами |
| `slides/urok-8.html` … `slides/urok-11.html` | Презентации уроков 8–11 (стрелки ← → или клик, F — полный экран) |
| `tutor.html` | Панель тьютора: прогресс всех учеников, их код, перепроверка решений |

## Включить сайт (GitHub Pages)

1. На GitHub откройте репозиторий → **Settings** → **Pages**.
2. В «Build and deployment» выберите **Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
3. Через минуту сайт будет доступен по адресу выше. Каждое изменение в ветке `main` публикуется само.

## Автоматическая отправка прогресса

Без настройки ученики сдают домашку **кодом сдачи**: кнопка «Получить код сдачи» → сообщение тьютору в мессенджер → вставить в панель тьютора.

Чтобы прогресс приходил **сам**, подключите бесплатную Google-таблицу (около 10 минут, один раз):

1. Создайте новую Google Таблицу (sheets.new), назовите, например, «Домашки Python».
2. В таблице: **Расширения → Apps Script**.
3. Удалите всё в редакторе и вставьте код из файла [`backend/google-apps-script.js`](backend/google-apps-script.js).
4. В строке `const PASSWORD = '...'` придумайте свой пароль. Нажмите 💾 «Сохранить».
5. **Развернуть → Новое развёртывание** → шестерёнка → **Веб-приложение**:
   - «Запуск от имени»: **я**;
   - «У кого есть доступ»: **Все**.
6. Нажмите «Развернуть», разрешите доступ своему аккаунту Google и скопируйте **URL веб-приложения** (заканчивается на `/exec`).
7. В репозитории откройте [`config.js`](config.js) → карандаш «Edit» → вставьте адрес в `endpoint: '...'` → «Commit changes».
8. Откройте `tutor.html` на сайте и введите пароль из шага 4.

Готово: когда ученик вписал имя и решает задачи, прогресс отправляется в таблицу автоматически, а панель тьютора обновляется каждые 2 минуты.

> Если вы позже поменяете код скрипта, сделайте **Развернуть → Управление развёртываниями → Изменить → Новая версия**, иначе будет работать старая версия.

## Что можно настроить

В [`config.js`](config.js):

- `endpoint` — адрес Google Apps Script (см. выше);
- `currentLesson` — номер последнего пройденного урока: на главной уроки после него помечаются «следующий» и «скоро».

Список уроков, их темы и ссылки на Colab — в [`assets/lessons.js`](assets/lessons.js).

## Как устроено

- `assets/harness.py` — песочница для кода учеников: ввод, вывод, черепашка `turtle` (как в PyCharm) и `ColabTurtle` (как в Colab), понятные ошибки по-русски.
- `assets/py-worker.js`, `assets/runner.js` — запуск Python в фоне браузера; бесконечный цикл останавливается через 10 секунд.
- `assets/hw-engine.js` — движок домашек и проверки задач (вывод программы на тестовых данных, проверка кода, сравнение рисунков черепашки).
- `hw/urok-N.js` — содержимое домашки N: теория, квиз, ошибки, задачи и тесты.
- `tools/build_slides.py` — сборка презентаций. Весь код на слайдах прогоняется Python, вывод и рисунки вставляются автоматически: `python3 tools/build_slides.py`.
- `backend/google-apps-script.js` — приёмник прогресса для Google-таблицы.
- `archive/urok-8-old.html` — прежняя версия страницы урока 8.

## Добавить новую домашку

1. Скопируйте `hw/urok-8.html` и `hw/urok-8.js` в `hw/urok-9.html` / `hw/urok-9.js`, в html поменяйте имя скрипта.
2. В `hw/urok-9.js` поменяйте `id: 'hw9'`, `lesson: 9` и содержимое задач.
3. В `assets/lessons.js` у урока 9 добавьте `hw: 'hw/urok-9.html', hwId: 'hw9'` — домашка появится на главной и в панели тьютора.
