Друг-программист рядом

Представь друга, который сидит рядом и в любой момент подсказывает код, предлагает варианты и находит ошибки.

ИИ-ассистент — программа, обученная на миллионах строк кода. Она понимает, что ты хочешь, и предлагает решения.

Многие среды разработки уже содержат ИИ внутри. Ещё есть отдельные сервисы: YandexGPT, GigaChat, DeepSeek и другие.

ПромптПишем запрос

«Напиши программу на Python: два игрока бросают кости по три раза каждый. Значения двух костей складываются и добавляются к очкам игрока. После трёх бросков суммы сравниваются и определяется победитель».
  • Сравни ответ с кодом с прошлого урока.
  • Сравни ответы у соседей — они разные!
  • Любую программу можно написать по-разному.

Задача 1: калькулятор

Функция принимает два числа и операцию и печатает результат. Ввод гарантированно верный.

def calculator(a, b, op):
    if op == "+":
        print(a + b)
    elif op == "-":
        print(a - b)
    elif op == "*":
        print(a * b)
    elif op == "/":
        print(a / b)

calculator(10, 4, "*")
40

Задача 2: сколько цифр в числе

Делим число нацело на 10, пока оно не станет нулём, и считаем шаги.

def digitCounter(n):
    count = 0
    while n > 0:
        n = n // 10
        count = count + 1
    print(count)

digitCounter(103)
digitCounter(7)
3 1

Задача 3: треугольник из звёздочек

Вспоминаем умножение строки на число.

def buildTriangle(height):
    for i in range(1, height + 1):
        print("*" * i)

buildTriangle(4)
* ** *** ****

Задача 4: палиндром

Слово читается одинаково слева направо и справа налево. Сравниваем первый символ с последним, второй — с предпоследним… до середины.

def isPalindrome(text):
    result = True
    for i in range(len(text) // 2):
        if text[i] != text[-1 - i]:
            result = False
    if result:
        print("Yes")
    else:
        print("No")

isPalindrome("121")
isPalindrome("шалаш")
isPalindrome("кот")
Yes Yes No

ИИ тоже ошибается

  • На сложных задачах ИИ путается, особенно в длинных условиях.
  • Олимпиадные задачи (например, Timus 1731) — слабое место.
  • ИИ может уверенно написать неправильный код.
Никогда не выдавай код нейросети за правильный, пока сам не разобрался и не проверил его.

Как писать хороший запрос

  • Короткие и чёткие предложения — с ними ИИ справляется отлично.
  • Пиши, на каком языке и для какой среды (Python, turtle, PyCharm).
  • Дай пример: что вводится и что должно получиться.
  • Большую задачу разбей на маленькие шаги.
  • Попроси объяснить код — и проверь, понятно ли тебе.
