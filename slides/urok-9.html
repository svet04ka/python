Что должно быть в игре

1. Поле

В консоли рисуется поле 3 × 3 с номерами клеток.

2. Ходы

Игрок вводит номер клетки, ставит X или O, ход переходит к другому.

3. Победа

Три одинаковых знака в ряд — игра заканчивается.

Если игрок ввёл не номер клетки, программа не должна ломаться — это тоже надо обработать.

drawBoard() — рисуем поле

def drawBoard(board):
    print("-" * 13)
    for i in range(3):
        print("|", board[0 + i * 3], "|", board[1 + i * 3], "|", board[2 + i * 3], "|")
        print("-" * 13)

board = list(range(1, 10))

try / except — защита от ошибок

def isValidInput(playerAnswer):
    try:
        playerAnswer = int(playerAnswer)
    except ValueError:
        print("Некорректный ввод. Вы уверены, что ввели число?")
        return False
    if playerAnswer < 1 or playerAnswer > 9:
        print("Некорректный ввод. Введите число от 1 до 9")
        return False
    return True

int("abc") обычно ломает программу. Внутри try ошибка не останавливает игру — Python переходит в except.

return возвращает значение туда, где функцию вызвали: True или False.

def takeInput(playerToken):
    valid = False

        if not isValidInput(playerAnswer):
            continue
        playerAnswer = int(playerAnswer)
        if str(board[playerAnswer - 1]) not in "XO":
            board[playerAnswer - 1] = playerToken

  • valid = False — пока ход не принят, крутимся в цикле;
  • continue — сразу на новый круг;
  • клетка свободна, если в ней ещё не X и не O;
  • занята — просим другую.

checkWin() — кто победил?

def checkWin(board):
    winCoord = ((0, 1, 2), (3, 4, 5), (6, 7, 8), (0, 3, 6),
                (1, 4, 7), (2, 5, 8), (0, 4, 8), (2, 4, 6))
    for coord in winCoord:
        if board[coord[0]] == board[coord[1]] == board[coord[2]]:
            return board[coord[0]]
    return False

8 выигрышных линий: 3 строки, 3 столбца, 2 диагонали.

Функция вернёт "X", "O" или False.

main() — главный цикл

def main(board):
    counter = 0
    win = False
    while not win:
        drawBoard(board)
        if counter % 2 == 0:
            takeInput("X")
        else:
            takeInput("O")
        counter += 1
        if counter > 4:
            tmp = checkWin(board)
            if tmp:
                print(tmp, "выиграл!")
                win = True
                break
        if counter == 9:
            print("Ничья!")
            break
    drawBoard(board)
  • counter считает ходы: чётный — X, нечётный — O;
  • проверять победу есть смысл после 5-го хода;
  • if tmp: — строка "X" или "O" считается истиной;
  • 9 ходов без победы — ничья, break.
