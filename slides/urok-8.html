Что такое функция

Функция — участок кода с именем. Он отделён от остальной программы и выполняется только тогда, когда его вызывают.

Мы уже пользовались готовыми функциями:

Первая своя функция

def sumAB(a, b):
    print(a + b)

Запускаем — и ничего не происходит. Функцию только объявили.

def sumAB(a, b):
    print(a + b)

sumAB(10, 40)
sumAB(30, 5400)
sumAB("30", "001")
50 5430 30001

Записать в блокнотКак устроена функция

  • в начале ключевое слово def;
  • потом имя функции;
  • в скобках — параметры (их может и не быть);
  • в конце — двоеточие :, как у циклов;
  • тело — с отступом в 1 табуляцию;
  • вызов — имя и значения в скобках.
def sumAB(a, b):
    print(a + b)

sumAB(10, 40)
# a = 10, b = 40
# print(10 + 40) → 50

Но какой смысл в функции, которая всегда рисует один и тот же квадрат?

Параметр size

def drawSquare(size):
    for i in range(4):
        forward(size)
        right(90)

drawSquare(50)
drawSquare(100)
drawSquare(150)

Параметр стоит везде, где черепашка идёт вперёд.

Зачем нужны функции

Короче

Код не повторяется: написал один раз, вызываешь сколько угодно.

Понятнее

По имени drawSquare сразу видно, что делает код, без комментариев.

Мощнее

Из простых функций собираются сложные узоры.

Узор из квадратов

Функции-фигуры

def drawTriangle(size):
    for i in range(3):
        forward(size)
        left(120)

def drawPolygon(size, edges):
    for i in range(edges):
        forward(size)
        left(360 / edges)

def drawRound(size):
    for i in range(360):
        forward(size)
        backward(size)
        right(1)

Подставь в узор вместо drawSquare любую другую функцию — получится новый узор.

Цвета по кругу: i % len(colors)

colors = ["red", "orange", "gold"]
for i in range(7):
    print(i, i % len(colors), colors[i % len(colors)])
0 0 red 1 1 orange 2 2 gold 3 0 red 4 1 orange 5 2 gold 6 0 red

colors[i] сломается, когда i станет больше количества цветов: IndexError.

Остаток от деления i % len(colors) всегда от 0 до len − 1, и цвета идут по кругу.

Разноцветный круг

colors = ["plum", "orchid", "mediumpurple",
          "slateblue", "indigo"]

def colorRound(size):
    speed(0)
    for i in range(360):
        color(colors[i % len(colors)])
        forward(size)
        backward(size)
        right(1)

colorRound(150)

Цвет тремя числами: RGB

Три числа от 0 до 255 — сколько в цвете красного, зелёного и синего.

  • (255, 0, 0) — красный
  • (0, 0, 0) — чёрный
  • (255, 255, 255) — белый
Сначала colormode(255), иначе ошибка bad color sequence.
colormode(255)
for i in range(360):
    color(255, int(i * 255 / 360), 0)
    forward(150)
    backward(150)
    right(1)

Градиент

Градиент — цвета, которые плавно меняются. Здесь номер луча i управляет цветом.

Итоги урока

  • Функция — код с именем, который работает только при вызове.
  • def имя(параметры): и тело с отступом.
  • Параметры делают функцию гибкой.
  • Из маленьких функций собираются большие узоры.
  • colors[i % len(colors)] — цвета по кругу, colormode(255) — для RGB.
