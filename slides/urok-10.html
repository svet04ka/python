Модуль math

  • math.ceil(x) — округлить вверх
  • math.floor(x) — округлить вниз
  • math.sqrt(x) — квадратный корень
  • math.pi — число π
  • math.sin, math.cos — тригонометрия
import math

print(math.ceil(4.2))
print(math.floor(4.8))
print(math.sqrt(81))
print(math.pi)
5 4 9.0 3.141592653589793

Длина окружности

Радиус вводится с клавиатуры. Длина окружности = 2 · π · R. Потом отбрасываем дробную часть, округлив вниз.

import math

R = float(input("Радиус: "))
length = 2 * math.pi * R
print(length)
print(math.floor(length))
Радиус: 10 62.83185307179586 62

Модуль random

  • random.choice(список) — случайный элемент
  • random.randint(1, 6) — случайное целое от 1 до 6
  • random.shuffle(список) — перемешать

Запусти несколько раз — результат каждый раз разный!

import random

fruits = ["яблоко", "груша", "банан"]
print(random.choice(fruits))
print(random.randint(1, 6))
random.shuffle(fruits)
print(fruits)

Первая версияИгра в кости

import random
player1 = input("Имя первого игрока: ")
player2 = input("Имя второго игрока: ")
dice1 = [1, 2, 3, 4, 5, 6]
dice2 = [1, 2, 3, 4, 5, 6]
score1 = 0
score2 = 0
for i in range(3):
    input(player1 + ", нажми Enter, чтобы бросить кости")
    result = random.choice(dice1) + random.choice(dice2)
    print("Выпало:", result)
    score1 = score1 + result
    input(player2 + ", нажми Enter, чтобы бросить кости")
    result = random.choice(dice1) + random.choice(dice2)
    print("Выпало:", result)
    score2 = score2 + result
if score1 > score2:
    print("Победил", player1)
elif score2 > score1:
    print("Победил", player2)
else:
    print("Ничья")

Два игрока бросают по две кости три раза. У кого сумма больше — тот победил.

input() — чтобы игра не пролетала за долю секунды.

Что не так с этим кодом?

  • Код для первого и второго игрока почти одинаковый.
  • Условие победы — отдельная часть логики.
  • Если захотим 3 игрока — придётся копировать ещё.
Одинаковые куски кода — сигнал: выдели их в функцию.

Улучшаем код, не меняя поведениеРефакторинг

import random

def rollDice():
    return random.randint(1, 6) + random.randint(1, 6)

def playerTurn(name):
    input(name + ", нажми Enter, чтобы бросить кости")
    result = rollDice()
    print(name, "выбросил", result)
    return result

def announceWinner(name1, score1, name2, score2):
    if score1 > score2:
        print("Победил", name1)
    elif score2 > score1:
        print("Победил", name2)
    else:
        print("Ничья")
player1 = input("Имя первого игрока: ")
player2 = input("Имя второго игрока: ")
score1 = 0
score2 = 0
for i in range(3):
    score1 += playerTurn(player1)
    score2 += playerTurn(player2)
announceWinner(player1, score1, player2, score2)

Игра работает так же, но код читается как рассказ: бросок, ход игрока, объявление победителя.

Чистый код: одна задача — три решения

Вывести все числа списка, которые меньше 10.

Понятно

for number in numbers:
    if number < 10:
        print(number)

Слишком сложно

print(list(filter(
  lambda x: x < 10,
  numbers)))

Опытно

print([n for n in numbers
       if n < 10])

Имена говорят за себя

a = int(input())
if a % 4 == 0 and a % 100 != 0 or a % 400 == 0:
    print("Да")
else:
    print("Нет")

Что делает этот код? Сразу не понять.

def isLeapYear(year):
    return year % 4 == 0 and year % 100 != 0 \
        or year % 400 == 0

year = int(input())
if isLeapYear(year):
    print("Високосный")
else:
    print("Обычный")
2024 Високосный

Правила чистого кода

  • Имя переменной объясняет, что в ней: apples, а не a.
  • Список — во множественном числе: numbers, а не number.
  • Имя функции — действие: drawBoard, isLeapYear.
  • Имена — на английском, слова слитно с большой буквы или через _.
  • Повторяющийся код — в функцию.
  • Комментарии — там, где без них не понять, а не на каждой строке.

Бонус: модуль time

  • time.sleep(2) — пауза 2 секунды
  • time.time() — секунды с 1 января 1970
  • time.ctime(t) — время в читаемом виде

Задача: какое время будет ровно через неделю? В неделе 60 · 60 · 24 · 7 = 604 800 секунд.

import time

week = 60 * 60 * 24 * 7
print(time.ctime(time.time() + week))
